# SkillPilot AI: Your Career Compass

Build a world-class, modern, premium AI SaaS website for my project called "SkillPilot AI".

PROJECT

SkillPilot AI is an AI Career Operating System that helps students, freshers, and job seekers become industry-ready using Artificial Intelligence.

The platform provides:

• AI Resume Analysis

• ATS Score

• Resume Improvement Suggestions

• Job Description Analysis

• Skill Gap Analysis

• Personalized Learning Roadmap

• AI Generated Assessments

• AI Career Chatbot

• Career Dashboard with Analytics

The website should look like a startup that has raised millions of dollars, not a college project.

- Add a theme toggle button in the top-right corner of the navigation bar.

- Support both Light Mode and Dark Mode.

- Detect the user's system preference on first visit.

- Save the selected theme in local storage so it persists across sessions.

- Ensure all pages, cards, charts, dialogs, and components automatically adapt to the selected theme.

- Add a smooth 300ms transition when switching themes.

Dark Theme:

- Background: #09090B

- Cards: #18181B

- Text: White

Light Theme:

- Background: #FFFFFF

- Cards: #F8FAFC

- Text: #111827

Replace the current logo everywhere in the website (Navbar, Sidebar, Login Page, Dashboard, Footer, Favicon, Loading Screen, Mobile Menu, Browser Tab, and Authentication Pages) with the uploaded SkillPilot AI logo.

Requirements:

- Use the uploaded logo as the official brand identity.

- Keep the logo sharp and high quality.

- Maintain proper spacing and alignment.

- The logo should scale correctly on desktop, tablet, and mobile devices.

- Create a transparent version if needed.

- Do not redesign or modify the logo shape—only optimize it for the UI.

- Use the logo consistently across the entire application.

### 3. Improve the Consistency Heatmap

The consistency heatmap on the dashboard is currently too dark.

Please:

- Make the heatmap colors brighter and easier to read.

- Use a modern GitHub-style gradient with higher contrast.

- Add smooth hover animations.

- Show a tooltip on hover displaying:

  - Date

  - Activity Level

  - Number of tasks completed

- Make the heatmap responsive.

- Add a subtle glow around highly active days.

- Improve spacing and rounded corners.
