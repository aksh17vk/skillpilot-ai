Docker is a platform used to package applications into containers.

Containers are lightweight and share the host operating system kernel.

Docker images are read-only templates used to create containers.

A Docker container is a running instance of an image.

Docker Hub is a public registry for storing and sharing Docker images.

Docker Volumes provide persistent storage outside the container lifecycle.

Bind mounts map a host machine directory directly into a container.

Docker Compose is used to define and run multi-container applications.

Environment variables can be passed to containers during runtime.

Docker networking allows containers to communicate with each other.
